# NIOR

NIOR is a responsive, static streetwear concept site built with HTML, CSS, and
vanilla JavaScript. Product details, images, prices, and contact channels are
demonstrations or configuration placeholders; no checkout, inventory, or
newsletter service is connected.

## Run locally

Open `index.html` in a browser, or serve the project root with a local static
server such as the VS Code Live Server extension.

## Deploy on Render

The root-level `render.yaml` defines a Render Static Site. In Render, create a
new Blueprint and connect this repository. Render publishes the repository root
(`.`) directly; there is no build command or start command.

The site automatically deploys when the configured repository branch changes.
For a manually configured Static Site, use:

- **Build command:** leave blank
- **Publish directory:** `.`
- **Start command:** not applicable

## Before launch

- Replace the temporary campaign and product images with approved NIOR assets.
- Confirm product names, descriptions, sizes, and prices.
- Configure official contact details and implement any desired order, contact,
  or newsletter service before describing those features as live.
